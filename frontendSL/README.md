# frontendSL

Interfaz web de Sabor Latino hecha con **React + Vite + TypeScript**.

## Crear el proyecto (solo una vez)

Desde la carpeta raíz del repositorio:

```
npm create vite@latest frontendSL -- --template react-ts
```

Cuando pregunte si la carpeta no está vacía, elegir **Ignore files and continue** para conservar este README.

## Correr en desarrollo

```
cd frontendSL
npm install
npm run dev
```

Queda en `http://localhost:5173`. Todas las llamadas a la API van en `src/api/`.
