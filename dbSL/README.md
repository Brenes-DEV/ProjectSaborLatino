# dbSL

La base de datos **no** se crea con scripts a mano: se crea con las **migraciones de Entity Framework** que están en `backendSL/Migrations/`.

Esta carpeta es para material de apoyo:

| Carpeta         | Contenido                                        |
|-----------------|--------------------------------------------------|
| `diagramas/`    | Diagramas de la base (entidad-relación, etc.)    |
| `datos-prueba/` | Scripts para cargar datos de prueba              |
| `consultas/`    | Consultas SQL útiles para revisar datos          |
